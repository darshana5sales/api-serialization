Gazette of India · G.S.R. 20(E)

Mandatory QR codes on API: what the guideline actually requires

Every Active Pharmaceutical Ingredient manufactured or imported in India must carry a QR code on its label at each packaging level, machine-readable, carrying eleven specific particulars. This is the full requirement, in plain language.

The notification

G.S.R. 20(E) at a glance

The regulation was introduced to address counterfeiting of Active Pharmaceutical Ingredients and to give the supply chain visibility it did not previously have — a substantial step towards an API supply chain free of fake raw material and low-quality product.

Ministry of Health and Family Welfare notification In force
Guideline
G.S.R. 20(E)

The requirement

What it requires

Every manufacturer or importer of an API in India must print a QR code on the product label at each level of packaging. That code must contain a defined set of information and must be readable by a software application, so the pack can be tracked and traced.

Failure point 01

Each packaging level

Not only the outer shipper. Every level that is presented as a unit carries its own compliant label, because every level can be separated from the others.

Failure point 02

A defined set of information

Eleven particulars, all of them, on every pack. Ten out of eleven is a finding, and the conditional fields still apply wherever the material has them.

Failure point 03

Readable with a software application

A decorative QR code that resolves to nothing does not satisfy this. It has to resolve, and what it resolves to has to match the pack.

The data

The eleven mandatory particulars

The guideline specifies exactly what the QR code must carry. The right-hand column is not part of the notification — it is what each field means once you are actually producing labels.

The eleven data fields a QR code on an API label must contain under G.S.R. 20(E)
#Required particularWhat it means in practice
01Unique product identification codeA code that identifies this product and no other. Held on the product master and applied to every batch of it.
02Name of the APIThe approved product name, matching your regulatory filings — not an internal shorthand.
03Brand name, if anyConditional. Printed only where a brand name exists for the material.
04Name and address of the manufacturerThe full registered address. For imports, the details of the manufacturer, held against the import licence.
05Batch numberCarried into every container serial generated from that batch, so a scan resolves back to the batch record.
06Batch sizeWith its unit of measure. A batch size without a unit is not a batch size.
07Date of manufacturingThe format on the human-readable label can be configured; the data in the QR payload stays unambiguous.
08Date of expiry or retestingWhichever applies to the material. Some APIs carry a retest date rather than an expiry date, and the label must reflect the right one.
09Serial shipping container codeThe GS1 SSCC. Unique to each individual container — fifty drums means fifty distinct SSCCs, not one repeated fifty times.
10Manufacturing or import licence numberWhichever applies. Manufacturers print the manufacturing licence; importers print the import licence.
11Special storage conditions, if requiredConditional. Temperature and handling requirements where the material has them.
Field 09 is where most manual approaches break SSCC codes have to be unique, sequential within an allocated range, and never reissued. That is manageable for one batch on a spreadsheet and unmanageable across products, sites and years — which is why SSCC ranges are normally allocated and controlled centrally by the serialization system.
11 / 11 Every particular is built into the APIQR label template and the QR payload, so a field cannot be forgotten on a batch.

Scope of the label

What "each packaging level" means

The requirement is not satisfied by labelling the outer shipper alone. Each level of packaging that is presented as a unit needs its own compliant label — because each is a distinct physical unit that can be separated from the others. A drum that leaves its shipper still has to be identifiable on its own.

Level 01

Primary pack

The container in direct contact with the material: the drum, the HDPE container, the fibre drum with its liner.

Level 02

Secondary pack

Where material is grouped or over-packed before shipment, and the group itself moves as one unit.

Level 03

Tertiary / shipper

The outermost unit that moves through the logistics chain, and the one most sites already label today.

Machine-readable

What "readable by a software application" means

The guideline requires the code to be readable by a software application for further tracking and tracing. In practice, that means an ordinary phone camera should resolve the code to a page showing the pack's data — no proprietary app, no dedicated scanner.

It also means the data has to exist somewhere authoritative. A QR code is a pointer; what matters is that it resolves, and that what it resolves to matches the pack in the reader's hand.

Anyone in the chain — a customer's goods-in team, an inspector, a logistics handler — gets the same answer from the same code, without being issued anything.
