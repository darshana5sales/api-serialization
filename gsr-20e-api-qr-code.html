The requirement

What does G.S.R. 20(E) require?

The amendment introduces a mandatory QR-code requirement under the Drugs Rules, 1945 for Active Pharmaceutical Ingredients (Bulk Drugs).

“Every active pharmaceutical ingredient (bulk drug) manufactured or imported in India shall bear Quick Response code on its label at each level packaging that store data or information readable with software application to facilitate tracking and tracing.”

G.S.R. 20(E) · The Drugs (Amendment) Rules, 2022

G.S.R. 20(E) in four parts

Who it applies to

API / Bulk Drug manufacturer or importer in India

Where it applies

QR code on the label at each packaging level

What it requires

11 prescribed particulars in a QR code

Readable by software

Readable by a software application for tracking and tracing

What “each packaging level” means

01 — Primary pack

The container in direct contact with the material: the drum, the HDPE container, the fibre drum with its liner.

02 — Secondary pack

Where material is grouped or over-packed before shipment, and the group itself moves as one unit.

03 — Tertiary / shipper

The outermost unit that moves through the logistics chain, and the one most sites already label today.

The data

The 11 mandatory particulars

G.S.R. 20(E) specifies the following particulars that must be stored as data or information in the QR code.

The eleven particulars that must be stored in the QR code on an API label under G.S.R. 20(E)
No. Required particular What it identifies
01 Unique product identification code Product identification
02 Name of the API API material
03 Brand name, if any The product brand, where applicable
04 Name & address of the manufacturer Manufacturer information
05 Batch number Production batch
06 Batch size Planned production quantity
07 Date of manufacturing Manufacturing date
08 Date of expiry or retesting Applicable product date
09 Serial Shipping Container Code (SSCC) Serialized container identity
10 Manufacturing or import licence number Applicable licence information
11 Special storage conditions, if any Required storage instructions
Particular 09 is where most manual approaches break SSCC codes have to be unique, sequential within an allocated range, and never reissued. That is manageable for one batch on a spreadsheet and unmanageable across products, sites and years — which is why SSCC ranges are normally allocated and controlled centrally by the serialization system.
11 / 11 Every particular is built into the APIQR label template and the QR payload, so a field cannot be forgotten on a batch.

Machine-readable

What does “readable by a software application” mean?

From physical pack to traceable information

The notification requires that the stored data or information must be readable by a software application for tracking and tracing.

In practical terms, the QR code must connect the physical API package with the relevant information needed for identification, tracking and tracing.
