01 What is an API (Active Pharmaceutical Ingredient)?

An Active Pharmaceutical Ingredient (API) is the active substance responsible for the intended effect of a pharmaceutical product. APIs are used to manufacture medicines such as tablets, capsules, creams, injectables and other pharmaceutical products.

API is also commonly referred to as a Bulk Drug.

02 What is API serialization?

API serialization is the process of assigning a unique identity to each API (Bulk Drug) pack and linking it with relevant product, batch and packaging information. This enables each pack to be identified, tracked and traced throughout the supply chain.

03 Why is API serialization important?

API serialization provides a more precise way to identify individual API (Bulk Drug) packs rather than relying only on product or batch information. It helps manufacturers and supply-chain stakeholders identify, track and trace packs throughout the supply chain, providing visibility into individual packs and their associated product and batch information. It also supports product traceability and helps meet applicable regulatory requirements, including G.S.R. 20(E).

It can support:

  • Individual pack identification
  • Product and batch traceability
  • Faster access to associated information
  • Supply-chain visibility
  • More targeted investigation and response
  • Controlled serialization and labelling workflows
04 What is G.S.R. 20(E) — Drugs (Amendment) Rules, 2022?

G.S.R. 20(E) is a Government of India notification that introduced the Drugs (Amendment) Rules, 2022, further amending the Drugs Rules, 1945. It was issued by the Ministry of Health and Family Welfare on 18 January 2022. It requires APIs (Bulk Drugs) manufactured or imported in India to carry a Quick Response (QR) code on the label at each level of packaging. The QR code must contain specified information that can be read by a software application to facilitate tracking and tracing.

Know the guideline

05 Does the requirement apply to imported APIs?

Yes. The QR-code requirement applies to applicable APIs and Bulk Drugs manufactured or imported in India.

Foreign API manufacturers supplying APIs or Bulk Drugs to the Indian market should therefore consider the applicable Indian QR-code labelling and information requirements under G.S.R. 20(E).

06 Is a QR code mandatory on API labels in India?

Yes. Under G.S.R. 20(E) — The Drugs (Amendment) Rules, 2022, applicable Active Pharmaceutical Ingredients (APIs) or Bulk Drugs manufactured or imported in India must carry a QR code on the label at each packaging level.

The QR code is required to store the specified information in a form that can be read by a software application for tracking and tracing.

Know all 11 particulars

07 What does “each packaging level” mean?

The notification states that API and Bulk Drug labels must carry a QR code containing the specified information at “each level of packaging.”

“Each packaging level” refers to the different levels at which an API or Bulk Drug may be packaged, handled or transported. The requirement should therefore be considered across the complete packaging structure, not only on the outer shipping pack.

01 — Primary pack

The individual packaging in direct contact with the API material.

02 — Secondary pack

A packaging level used to group or protect one or more primary packs.

03 — Tertiary / shipper pack

The outer packaging unit used for storage, handling or transportation.

08 What information must the API QR code contain?

The QR code must contain the 11 mandated particulars specified under the requirement.

These include product identification code, API name, brand name, manufacturer details, batch information, manufacturing and expiry or retesting dates, Serial Shipping Container Code (SSCC), applicable licence information and special storage conditions where required.

See all 11 particulars

09 What is an SSCC (Serial Shipping Container Code)?

SSCC (Serial Shipping Container Code) is an 18-digit unique number used to identify an individual logistics or shipping unit, such as an API container or shipment pack.

In API serialization, it helps uniquely identify an individual pack and link it with relevant product and traceability information.

SSCC structure

Extension digit+GS1 company prefix+Serial reference+Check digit

10 What does “readable by a software application” mean?

The QR code is not intended simply to be a visual code printed on the label.

The information encoded in the QR code must be machine-readable by a software application so that the associated information can be accessed to facilitate tracking and tracing.

In a serialization workflow, the software application connects the encoded identity with the relevant product, batch, packaging and traceability records.

Understand software readability

11 What happens when an API QR code is scanned?

When the QR code is scanned using a compatible software application, the encoded information can be read and associated product and pack details can be accessed.

Depending on the information stored and the system used, this can support:

  • Product identification
  • Batch identification
  • Pack or container identification
  • Manufacturing and expiry information
  • Traceability information
  • Verification and record access
