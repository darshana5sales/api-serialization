Frequently asked questions

API serialization, answered plainly

The twelve questions we are asked most often by API manufacturers, quality heads and regulatory affairs teams — answered without the sales language.

Common questions

If yours is not covered here, ask us directly — a specialist replies within one working day.

What is an API?

An Active Pharmaceutical Ingredient is the active component of a formulation product — a tablet, capsule, cream or injectable. In short, it is the raw material used to manufacture medicines.

In Indian industry usage it is also called a bulk drug. The two terms mean the same thing, and the QR code guideline applies to both names equally.

What is API serialization?

Start with serialization itself: it is the process of giving a product a unique identity through a standard set of details — GTIN, SSCC, SKU, product ingredients, batch number, manufacturing and expiry dates — which together make it uniquely identifiable and easily traceable through the supply chain.

API serialization applies that to an API or bulk drug, so it can be tracked and traced through the chain: where it is now, and where it has been.

Is it compulsory to have a QR code on an API pack in India?

Yes. The Government of India has made it compulsory for every API pack manufactured or imported in India to carry a QR code, as per the gazette published by the Ministry of Health and Family Welfare on 18 January 2022 under number CG-DL-E-19012022-232768. Guideline G.S.R. 20(E) came into force on 1 January 2023.

The full notification is available on the resources page, free and without a form.

What information must the QR code contain?

Eleven particulars: unique product identification code, name of the API, brand name if any, name and address of the manufacturer, batch number, batch size, date of manufacturing, date of expiry or retesting, serial shipping container code, manufacturing or import licence number, and any special storage conditions required.

See each field explained in practice →

Does the QR code go on every packaging level?

Yes. The guideline requires a QR code on the label at each packaging level — primary, secondary and tertiary. Each is a distinct physical unit that can be separated from the others, so each needs its own identity.

Labelling only the outer shipper is one of the most common gaps we find when reviewing existing labels.

How does this benefit API manufacturers, beyond avoiding penalties?

At present the API industry has no standard set of rules for track and trace and remains largely unorganised, which means no supply chain visibility and a large information gap — precisely what invites counterfeiters into the market. Counterfeiting is a global problem that ends up affecting public health and reducing trust in the healthcare system.

Serialization guarantees API quality and safety, and gives you complete supply chain visibility, so the source of a problem can be identified quickly and contained. Downstream, it helps every member of the chain with inventory management, verification, recalls and reduced supply delays.

How quickly can we be compliant?

Typically four to five working days from kick-off to your first compliant printed label. APIQR is a cloud application, so there is nothing to procure and nothing to change on the packing line — the time goes on setting up your product masters and label templates, not on building software.

Is it cloud-based, or does it install on our servers?

Fully cloud-based. Your team logs in through a standard web browser with a company code, username and password, and can work from the plant, the office or anywhere else with a connection. No on-premise servers, no heavy IT setup.

What happens after a batch is approved?

Serialized SSCC codes are generated automatically, typically within five to ten minutes of approval. Once they exist, the labels appear under Print Pending and become available for printing.

Can an approved batch be edited afterwards?

No — and that is deliberate. Once a batch is approved it locks, which preserves data integrity and is a key requirement for regulatory audits. If something is wrong, the batch is rejected or cancelled with a recorded reason rather than quietly amended.

Does the software support GTIN and NDC standards?

Yes. APIQR supports GS1-compliant GTIN generation as well as NDC (National Drug Code) fields for products sold into the United States market. SSCC number ranges are managed centrally through Core Config, so serials never collide across products or sites.

Who can approve or print a batch?

Only the people you authorise. APIQR includes granular role-based user management with Administrator, Supervisor and Operator roles, and rights can be set per user or cloned from an existing template.

Reprints require the authorised user to log in again, which is what protects against unauthorised label duplication.
