What it is

What is API serialization?

From product identity to pack-level traceability

API serialization is the process of assigning a unique identity to each API (Bulk Drug) pack and linking it with relevant product, batch and packaging information. This enables the pack to be identified, tracked and traced throughout the supply chain.

A QR code carries the machine-readable information. The serialization system connects that information with the product, batch and individual pack records behind it.

API · Bulk Drug · Traceability An Active Pharmaceutical Ingredient (API), commonly referred to as a Bulk Drug, is the active substance used in the manufacture of pharmaceutical products. Serialization gives each pack a traceable identity.

Batch versus pack

Why not just use batch information?

A batch identifies the production run.
Serialization identifies the individual pack.

A batch number tells you which production run a material came from. However, multiple packs or containers can belong to the same batch.

Serialization adds another level of identification by associating a unique identity with each applicable pack or container.

This creates a clearer connection between what the product is, which batch it came from, and which specific pack is being identified.
